# T13 - feasibility: can the coherency-edge network learn torsion once the excitation varies?

> Generated by `pipeline/k_report.py` from the CSVs and JSONs in this folder - do not edit by hand.
> EC-comment analysis, **not part of `results/paper/PAPER_RESULTS.md`**. Author-approved feasibility round (2026-11-23).
> **A screen, not a result:** 400 epochs (the paper trains 5000), one seed (123), one training run per arm. Intervals are over test structures, not over training runs.

## The question

T11 retrained EdgeGAT + coherency at N = 600 with one new excitation record per structure: it scored 0.41 on every test set with **T1 ~ 0.01** (best epoch 83, then validation loss rose while training loss fell). EdgeGAT + orientation scored 0.71-0.73. Hypothesis: between resonances most of the 400 coherency bins are a record-specific random pattern (|gamma| 0.1-0.7 between independent inputs with ~10 Welch segments over 60 s; T12 fig. 3), which a small training set memorises instead of the resonance-bin phase. T13 screens three levers that should each weaken that memorisation, at 400 epochs: **augmentation** (4 records per training structure, one drawn per epoch), **record length** (120 s: 22 Welch segments instead of 10), and **population size** (N = 2000). Decision line fixed beforehand: T1 MAC > 0.3 on the new-excitation test sets counts as "clearly above T11's 0.01".

- **Records.** Record k of structure i is `SeedSequence([base_k, i])` (T11's seeding patch, `h_common.resimulate_payload`), bases [20261125, 20261131, 20261132, 20261133]; base_0 = 20261125 is T11's training base, so record 0 is T11's stored sample, reused byte for byte. The N = 2000 arm's 600 N600 structures are copied from T11 (byte-identical, checked); its other 1400 are simulated with the same base.
- **Augmentation** (`k_train.py`): two in-memory substitutions in the library - the training dataset holds the K library datasets, and the training loader draws, before every epoch, `slot[i] = default_rng([20261130, epoch]).integers(0, K, n)` (T4's per-epoch idea; a Generator of its own, so torch's shuffling/dropout stream is untouched). Each epoch has the same number of training graphs as K = 1.
- **Validation** (best-epoch selection): the 92 N600 validation structures with their base-20261125 record (60 s) for every N600 arm, so best epochs are selected on the same data; the 120 s arm validates on the same structures and seeds at 120 s; the N = 2000 arm on its own 300 validation structures (base 20261125).
- **Record length** (`k_common.resimulate`): `SIM.T_TOTAL = 120` patched in memory for the one call (60 restored), Welch unchanged (Hamming 2048/1024, 400 bins), so the feature dimensions are the paper's.

Test sets (best-validation checkpoint, T5's `c_rescore.evaluate` unchanged):

Reading (an interpretation, not tested here): every coherency arm predicts a T1 shape about 1 % the size of its B1, i.e. it has driven its T1 output to almost zero, and what little is left resembles a bending shape. Zero is what a mean-squared-error loss gives for a signed target whose sign the input cannot settle. The orientation arms output a full-size T1 (0.65 of B1), and their edges say which way each edge points. This suggests the coherency arms lack a cue for *which side of the deck is which* (the T1 sign), rather than (only) memorising record noise: the same network trained on the single shared record reached T1 0.80 on that record (T11, `edgegat_N600`), so the shared record supplied such a cue, and a different record per structure removes it. None of the three levers adds one. Not tested here.

## Caveats

- **400 epochs, one seed (123), one run per arm: a feasibility screen only.** Single runs can differ by several hundredths between seeds (T1's multi-seed ablation); a lever that moves T1 by less than ~0.05 is not distinguished from seed noise here.
- 400 epochs is 8 % of the paper's budget. Arms whose validation loss was still improving at 400 (Training table) are under-trained relative to the paper protocol; arms that peaked early are not.
- The augmentation arm sees each record of a structure ~100 times in 400 epochs instead of 400 times one record; it costs no more per epoch. The 120 s arm changes both the training and validation records (22 Welch segments). The N = 2000 arm validates on 300 different structures, so its best epoch is selected on a different set.
- Only the excitation record (and, in one arm, its length) varies; spectrum, amplitude, spatial coherence of the support inputs, measurement noise and damping are the paper's throughout.
- `fresh_test` shares one new record across its 500 structures (T5's generation); `paper_varexc` gives each structure its own. Real-bridge inputs are the corrected Phase P features; the real records are 59-148 s at 128 Hz.
