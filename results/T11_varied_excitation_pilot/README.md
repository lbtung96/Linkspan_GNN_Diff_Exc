# T11 - varied-excitation pilot: does training on a new excitation record per structure fix the collapse?

> Generated by `pipeline/h_report.py` from the CSVs and JSONs in this folder - do not edit by hand.
> EC-comment analysis, **not part of `results/paper/PAPER_RESULTS.md`**. Author-approved pilot (2026-11-23); every other EC task stays paused.
> Protocol: the paper's (N = 600 split 508 / 92, EdgeGAT hyperparameters, seed 123, 5000 epochs, best-validation checkpoint), **one seed, N = 600 only**.

## The question

T5 found that every paper structure (training, validation and test) was excited by the same white-noise record: `simulate_uniform_inertial_u3_white_noise.py` sets `SEED = 12345` (line 62) and calls `np.random.default_rng(SEED)` afresh inside the per-structure simulation (line 344). On a new record the networks collapse (main network 0.934 -> 0.377 on the same 500 new structures), through the edge coherency (T5's input swap). The pilot asks whether that is a property of the method or of the training data: retrain with a **different record for every structure** and test on new records.

**Decision lines, stated before the runs** (new-excitation mean MAC of the varied-excitation coherency arm, `ec_varexc_edgegat_N600`): >= ~0.8 -> "the approach generalises when trained correctly"; 0.5-0.8 -> "partly"; < 0.5 -> "does not". Primary set: `fresh_test` (new structures and a new record, T5's untouched set); `paper_varexc` (paper test structures, a new record each) is reported beside it.

## Design

**Excitation seeding** (`h_common.py`). The simulator reads its module global `SEED` at call time, and `np.random.default_rng` accepts a `SeedSequence`, so the per-structure record is injected in memory, as s0 / T5 patch module globals: `SIM.SEED = SeedSequence([base, sample_index])` immediately before each structure's simulation, 12345 restored after. `sample_index` is the paper's global index (the four digits of the file name). Bases: 20261125 training + validation, 20261126 the paper's test structures (`paper_varexc`), 20261127 the real bridges' FE-simulated ceiling (index = LOOCV position, three records k = 0, 1, 2 per bridge). No library file is edited.

**Data** (`h_prepare.py`). The 508 training and 92 validation structures of `N600_train/val.txt`, and the 500 of `test.txt`, re-simulated with the generator's own broadband path (FE solve from `params_json`, all 15 modes, 1.5-20 Hz zero-phase band-pass, Hamming Welch 2048/1024, 400 bins, row-normalised PSD; edges by the generator's `build_cpsd_edge_payload` / `build_cpsd_full_edge_payload`). Each written sample is the stored sample with the five excitation-dependent arrays replaced (`x_psd`, `x_psd_row_scale`, `edge_attr_cpsd`, `edge_attr_cpsd_resonance`, `edge_attr_cpsd_full`); every other key - graph, labels, matcher record, parameters - is copied and checked byte-identical on read-back.

**Arms** (`h_train.py`): `fr_train.main()` unchanged (as T1's `t_train.py`), with `fr_train.jobs()` returning the job and fr_train's own `--pool`, `--train-list`, `--val-list`, `--run-root` options; 2 torch threads each, the two in parallel.

| run | layer / edge input | training data | paper twin (same structures, record 12345) |
|---|---:|---:|---:|
| ec_varexc_edgegat_N600 | EdgeGATConv / 800-d complex coherency | 508 / 92, record per structure (base 20261125) | `edgegat_N600` |
| ec_varexc_edgegat_geomorient_N600 | EdgeGATConv / edge orientation (cos, sin), fr_edge_modes | 508 / 92, record per structure (base 20261125) | `edgegat_geomorient_N600` |

**Test sets** (all scored with T5's `c_rescore.evaluate`, imported unchanged; `h_eval.py`):

| set | structures | excitation |
|---|---:|---:|
| paper | paper test set (500) | 12345 (the training record) |
| paper_varexc | the same 500 | a new record per structure (base 20261126) |
| fresh_test | 500 new (T5, parameter seed 20261123) | one new record shared by all (20261124) |
| fresh_test_paperexc | the same 500 new | 12345 |

**Real bridges** (`h_real.py`): zero-shot through `s5_zeroshot.load_structures` / `evaluate` (corrected Phase P field features via fr_common, hybrid graphs; torch default threads as s5); FE-simulated ceiling through s6's own functions (case a: every FE node, the generator's broadband path) for the paper record and three new records per bridge. The paper never scored an orientation arm on the bridges; here its edge input is `fr_edge_modes.orientation` of each hybrid graph's own `edge_attr_geom` (checked below).

## Verdict

- **Coherency arm trained on varied excitation, new-excitation mean MAC: 0.407 [0.399, 0.415] on `fresh_test`, 0.412 [0.404, 0.420] on `paper_varexc`** (paper twin `edgegat_N600`: 0.411 / 0.404; on the paper's own set it scored 0.866). Against the decision lines: **"does not"**.

## Caveats

- One training seed (123) and one population size (N = 600, 508 training structures); intervals are over test structures, not over training runs. N = 2000 was not retrained with varied excitation.
- `fresh_test` uses one new record shared by all 500 structures (T5's generation); `paper_varexc` a new record per structure. They test the same thing from two sides (a record never seen in training).
- Validation (best-epoch selection) is on the varied-record validation structures; it never saw a test record.
- The varied-record training is the minimal change: same structures, labels, graphs, features pipeline and hyperparameters; only the excitation record differs per structure. No other excitation property (spectrum, amplitude, spatial coherence of the support inputs, record length, noise) was varied.
- Real-bridge zero-shot reads the corrected Phase P field inputs (fr_common.REAL_FEATURES), as the paper pipeline now does; the orientation arms' bridge inputs are new here (the paper has no such rows).
- The ceiling uses three records per bridge; its spread across records is shown.
